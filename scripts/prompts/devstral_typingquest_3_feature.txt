あなたはScratch 3.0のproject.json形式に詳しいプログラミング講師です。
小学生向けタイピングRPG「タイピングクエスト」の、フェーズ1(初期化・選択画面)を新規実装したいです。

# 仕様書抜粋(7.2 処理フロー詳細「フェーズ1：初期化・選択」)
旗が押された時、全変数を初期化しタイマーを開始する。
難易度選択ボタンを表示し、Max_Miss（簡単:20, 普通:10, 難しい:5, デスモード:0）を設定する。
キャラクター選択ボタンを表示し、選択に応じてパラメータ
（キャラ1: Base_Damage = 20 / キャラ2: Max_Miss += 10 / キャラ3: Heal_Amount = 30）を補正する。

# キャラクター対応表(企画書より)
キャラ1＝攻撃特化＝スプライト名「ネコ」
キャラ2＝ミス許容特化＝スプライト名「ナノ」
キャラ3＝回復特化＝スプライト名「ピコ」

# このプロジェクトの命名規則(CLAUDE.mdより)
- 変数名・ブロードキャスト名は英略語や記号を使わず、ひらがな・カタカナ・日本語で意味が伝わる名前にする
  (例: たいりょく、ステージ、じょうたい、うごいている、のこりじかん)
- 状態管理は「じょうたい」のような変数で局面を文字列管理し、ブロードキャストで遷移を通知するパターンを使う
- ブロックIDはスプライト名(ひらがな・カタカナ)＋連番で命名する(例: ステージ1, ステージ2, プレイヤー1)

# 現状の実装(タイピングクエスト.sb3)
- Stageターゲット: variables = {"変数": 0} のみ、blocks = 0個(何も実装されていない)
- スプライト「ネコ」「ナノ」「ピコ」: いずれもvariables = {}、blocks = 0個(コスチュームのみ用意済み)

# 依頼内容
1. フェーズ1に必要なグローバル変数を、このプロジェクトの命名規則に沿った日本語名で設計してください
   (例: Max_Miss → 「ゆるすミスかいすう」のような形。英語名との対応も併記してください)。
2. 「旗が押されたとき」に全変数を初期化するStage側のスクリプトを、Scratch3.0のproject.json形式の
   blocks JSONとして出力してください。ブロックIDのプレフィックスは「じゅんび1_」を使ってください。
3. 難易度選択(4択: かんたん/ふつう/むずかしい/デスモード)に応じてMax_Miss相当の変数を設定するスクリプトを、
   同様にJSON形式で出力してください。「なんの難易度が選ばれたか」をブロードキャストで次のフェーズに伝える設計に
   してください。ブロックIDのプレフィックスは「じゅんび2_」を使ってください。
4. 出力する際は、既存のブロックID(まだ0個なので衝突の心配はありませんが、将来のフェーズ2以降で追加される
   ブロックと衝突しないよう)採番ルールについても一言コメントしてください。
